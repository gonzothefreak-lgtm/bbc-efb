# EFB shell and UI

- App frame: compact dark borderless Windows shell, custom window controls, and usable minimise, maximise, restore, close and resizing. Hybrid adaptive layout reflows where useful and scrolls where minimum usable dimensions require it.
- Title-bar icon: use the orange flight data recorder from the centre of the Black Box Club badge beside the BBC EFB title. Use a 40 px logical width and preserve the artwork’s aspect ratio. The [transparent icon preview](<../reference/04_REFERENCE_ASSETS/BBC EFB Teasers/Recorder Corner Icon.png>) is a design reference.
- Colour palette: use the Classic Blue navy work surface (`#0B1420`), panel fill (`#142131`), borders (`#283B50`), blue text accent (`#64B1FF`), selected-tab fill (`#175286`) and secondary text (`#A7BBD0`). Keep the orange recorder icon and use warm orange (`#F69955`) as a secondary accent for dashboard charts. Keep status colours paired with explicit labels.
- Dispatch: default Section on launch. Show a clearly labelled placeholder in the first build. The functional pre-flight workflow is deferred to a later development phase.
- In-Flight: use the first build to demonstrate the right-hand Modules launcher with one or two selectable UI examples. Start with Aircraft Status and Radios. Each opens a clearly labelled placeholder panel. Keep the launcher accessible during resizing and follow the shared visual system. Functional modules are deferred. Auto-collapse behaviour remains open.
- Logbook: present the approved pages and views described in [Logbook and Flight Recorder](04_LOGBOOK_AND_RECORDER.md).
- Flight History typography: start with the Compact density in Segoe UI. Use smaller table text with aligned numbers. The preview uses 11 px table text and 28 px rows as starting values for Windows display-scaling verification.
- Settings: make it available throughout the EFB. Include SimConnect diagnostics, Flight Logging & Privacy, and Data Management. Export All Data and restorable backup are distinct.
- Flight Logging & Privacy: let pilots control automatic logging and which optional flight information and telemetry are saved. Explain what each choice affects and give pilots separate controls for existing records. See [Storage and telemetry preferences](04_LOGBOOK_AND_RECORDER.md#storage-and-telemetry-preferences).
- Time display: add a saved app-wide choice between `Zulu (UTC)` and `Local time` using the pilot's Windows time zone. Apply it to timestamps that can be converted reliably, and identify the displayed time basis. Leave elapsed durations and date-only entries unchanged.
- Persistent footer: show independent side-by-side SimConnect connection and Flight Logging states. Show the simulator identified by Core in the connection text, for example `Connected to MSFS 2020` or `Connected to MSFS 2024` once MSFS 2024 support is implemented and verified. If the simulator version is unknown, show `Connected` without a version. SimConnect opens Settings > SimConnect > Connection Diagnostics. The approved Flight Logging labels are `Inactive`, `Ready`, `Active` and `Interrupted`. Flight Logging provides access to current-flight details. Show `Start Logging` and `Stop Logging` directly in the footer alongside the statuses, each only when the Recorder can accept that action. Manual Stop requires confirmation.
- SimConnect errors: show `Error` and a short plain-language reason when Core reports a connection or communication failure. Keep technical details and any available next action in Connection Diagnostics. Use `Disconnected` for a normal offline state. Flight Logging continues to show its own state, including `Interrupted` when a recording is affected.
- While logging is active, closing the app presents Cancel or Save & Exit. Keep incomplete flights truthful and report save failures.

Use the preserved illustrated UI Standards v1.2 and Logbook Design Record v1.2 for design reference. Sample metrics and historical illustrations are not implementation evidence. Test narrow layouts, Windows scaling, keyboard navigation and accessible state indicators in a real concept.
