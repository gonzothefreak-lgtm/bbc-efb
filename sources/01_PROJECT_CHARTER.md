# Project charter

BBC Integrated Workstation and EFB for VATSIM is a Windows 10/11 simulation workstation that reduces switching among planning, in-flight and logbook tools. The priorities are dependable pilot workflows, trustworthy flight records and minimal impact on MSFS frame times.

## Approved NEW C0.1 target

Deliver the complete EFB shell and the full approved Q1-Q14 Logbook feature set, with genuine local read-only MSFS 2020 automatic Flight Logging and manual override. Basic saved layout preferences are in scope. Advanced drag, docking and presets belong to C0.2 onward.

The immediate owner goal is a runnable first whole-EFB build with the full approved Logbook scope, including genuine automatic Flight Logging from read-only MSFS 2020 telemetry. See [Decisions and Readiness](08_DECISIONS_AND_READINESS.md). Unfinished Dispatch and In-Flight integrations can be clearly labelled placeholders. C0.1 must represent unsupported features and metrics truthfully.

The old C0.1-C0.3 app builds are historical. The current Core candidate and test evidence are documented in [Status and Evidence](07_STATUS_AND_EVIDENCE.md).
